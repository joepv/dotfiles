# Solarized Osaka for Yazi

A Yazi flavor inspired by
[Solarized Osaka](https://github.com/craftzdog/solarized-osaka.nvim)
by craftzdog.

The palette follows the actual Solarized Osaka Neovim palette rather
than the original Solarized palette.

## Installation

Copy this directory to:

```text
~/.config/yazi/flavors/solarized-osaka.yazi/
```

Then configure Yazi:

```toml
[flavor]
dark = "solarized-osaka"
```
